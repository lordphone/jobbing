# Figure — Associate AI Engineer

Remote (posting tags #LI-Hybrid). No job ID in the posting.

Figure (NASDAQ: FIGR): blockchain-native lending / capital markets; $22B+ HELOCs originated; YLDS stablecoin.

## About the Role
Figure's AI Engineering team builds and operates production AI systems. Associate AI Engineer helps operate and improve conversational AI systems while developing into a full-stack AI engineer. ~Half: technical operation of AI-powered chat, voice, and customer-support services (agent workflows, API integrations, testing, analytics, knowledge retrieval, security, production releases). Other half: Python services, APIs, data pipelines, evaluations, internal tools. Not a content-management or prompt-writing position.

## What You'll Work On
### Conversational AI Systems
- Improve AI chat and voice services for customer-service and lending workflows
- Build/maintain agent workflows, API-integrated tools, guardrails, retrieval rules, escalation paths
- Review workflows for logic errors, unsafe behavior, routing conflicts, unnecessary model context
- Disciplined dev, staging, testing, review, production-release practices
- Partner with domain experts (customer experience, policies, lending ops)
- Translate business knowledge into reliable system behavior
- Decide workflow logic vs deterministic code vs retrieval vs LLM vs product change

### Evaluation and Analytics
- Automated tests and simulations for conversational workflows
- Containment, escalation, answer quality, task completion, customer-impact metrics
- Tagging, monitoring, QA systems for production conversations
- Analyze failures; turn production evidence into prioritized improvements
- Pipelines making conversational data available to analytics/reporting
- Controlled experiments and incremental rollouts measuring business outcomes

### Full-Stack AI Engineering
- Python services and APIs exposing AI capabilities
- Integrations between AI systems and internal services
- Data and evaluation pipelines in Python and SQL
- Internal tools and UIs
- Deployment, monitoring, containerization, CI/CD

### Security and Governance
- Inventory/review conversational tools accessing internal or third-party APIs
- Sensitive operations use deterministic validation, not model judgment
- Handling of customer data, credentials, PII, regulated workflows
- Auditability for workflow changes and production behavior
- Escalate security, compliance, reliability concerns

## Must-Haves
- Strong programming fundamentals and practical Python
- Working SQL and structured data analysis
- Break ambiguous problems into testable components
- Read unfamiliar code and trace system behavior
- Strong written communication, attention to detail
- Interest in AI behavior, analytics, backend systems, product workflows
- Validate assumptions and measure outcomes
- Collaborate with engineers and nontechnical domain experts
- Desire to grow into full-stack production AI engineer

## Strong Signals
- Built an API, backend service, automation, data pipeline, or internal tool
- Evaluated LLMs, conversational agents, or probabilistic systems
- Experimental design, statistics, causal inference, applied econometrics
- Testing nondeterministic systems
- RAG, agent tools, workflow engines, model evaluation
- Distinguish deterministic-logic problems from LLM-suited ones
- Translating domain/policy requirements into software behavior

## Nice-to-Haves
- Degree/research in economics, CS, statistics, engineering, or quantitative field
- Graduate training with empirical research and substantial programming
- TypeScript or modern frontend framework
- Cloud, Docker, CI/CD, IaC
- Experimentation systems, analytics platforms, BI tools
- Lending, fintech, healthcare, or regulated environment
- Customer-support or contact-center systems

Prompt-writing only; pure researchers; won't collaborate with domain experts; accept model outputs without evaluation; default to LLM when deterministic code is safer; want narrow role without operational responsibility.
