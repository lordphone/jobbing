## About the team

The Akamai Inference Cloud team is part of Akamai's Cloud Technology Group. They design, implement, and operate AI platforms enabling customers to run inference models and developers to create applications. The Control Plane & Developer Experience team owns the API platform, developer tools, security, authentication, billing integration, and user-facing interfaces.

As a Software Engineer I on the Control Plane & Developer Experience team, you will build and maintain customer-facing platform features across the Akamai Inference Cloud control plane, with hands-on exposure to API platform development, cloud services, and AI infrastructure.

## Responsibilities

- Developing and maintaining services for control plane including API endpoints, configuration management, and platform workflows
- Building customer-facing features that enable users to configure, manage, and interact with inference platform resources
- Writing well-tested, well-documented code and participating in code reviews to maintain engineering standards
- Collaborating with engineering and product teams to translate requirements into reliable platform capabilities
- Contributing to platform reliability through monitoring, debugging, and operational support of control plane services

## Qualifications

- Bachelor's/Master's degree in Computer Science or its equivalent
- Proficiency in at least one programming language such as Python, Go, or JavaScript
- Familiarity with RESTful APIs and basic cloud computing concepts
- Familiarity with Git, GitHub workflows, and modern software development practices
- Curiosity and a desire to learn cloud platform and API development patterns
- Solid problem-solving skills and the ability to work effectively in a collaborative engineering team
